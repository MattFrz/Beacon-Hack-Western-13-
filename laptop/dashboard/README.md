# dashboard

Owner: Zain. Vite + React + three.js (react-three-fiber). Torso and chest camera cone, optional live JPEG from `telemd` (team monitoring, local network only), objects at their 3D positions, fingertip-to-target line, spoken cue as a caption, mode banner (LIVE / HOLD / LOST), process health, timing panel, replay scrubber. Reads the `bridge` WebSocket. Never on the wearer's path. JSON markers are enough if JPEG is off. Design: [`docs/nathans-revision.md`](../../docs/nathans-revision.md).
